# Features Guide

## What is TOON?

- See [TOON Spec](https://github.com/toon-format/spec)
- Official [@toon-format/toon](https://github.com/toon-format/toon) SDK

## Conversion

- Uses `encode()` and `decode()` from the official library
- Canonical output, round-trip determinism

## Editor

- CodeMirror 6, syntax highlighting for JSON/TOON
- Error highlighting, jump-to-error

## Presets

- Gallery of practical examples

## History & Projects

- IndexedDB storage, export/import, zip download

## Batch Conversion

- Drag & drop files/folders, zip output

## Transform Rules

- Bulk rename, filter, prefix, value mapping

## Metrics

- Local-first, privacy-aware, exportable

## Firebase Sync

- Optional, feature-flagged, Auth + Firestore only

## PWA & Capacitor

- Offline-ready, installable, mobile-first

## CI/CD

- GitHub Actions, deploy to Pages
