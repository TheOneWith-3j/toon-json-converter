# Features Guide

## What is TOON?

- See [TOON Spec](https://github.com/toon-format/spec)
- Official [@toon-format/toon](https://github.com/toon-format/toon) SDK

## Conversion

- Uses `encode()` and `decode()` from the official library
- Canonical output, round-trip determinism
- Quick actions for format/canonicalize, swap, copy, clear, download, and repair
- Side-by-side comparison with size delta and diff summary

## Editor

- CodeMirror 6, JSON syntax highlighting, and TOON editing
- Error-line highlighting and keyboard conversion shortcut

## Presets

- Gallery of practical examples

## History & Projects

- IndexedDB storage, named projects, search, delete, export/import, and batch ZIP download
- Optional Firebase project sync when public Firebase config is provided

## Batch Conversion

- Multi-file selection, drag-and-drop, and ZIP output

## Transform Rules

- Bulk rename, filter, prefix, value mapping

## Metrics

- Local-first, privacy-aware, locally persisted conversion metrics

## Firebase Sync

- Optional, feature-flagged, Google Auth + Firestore project sync

## PWA & Capacitor

- Offline-ready, installable, mobile-first with tabbed editor panes

## CI/CD

- GitHub Actions, deploy to Pages
